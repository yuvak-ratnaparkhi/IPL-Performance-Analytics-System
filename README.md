# 🏏 IPL Performance Analytics System

An end-to-end IPL Analytics project built using PostgreSQL, SQL, and Power BI to analyze historical IPL match data and generate meaningful insights about teams, players, venues, and seasons.

---

## Project Overview

The IPL Performance Analytics System transforms raw IPL datasets into interactive reports and dashboards.

The project follows a complete analytics workflow:

* Data Collection
* Database Design
* Data Cleaning
* Data Analysis
* Reporting Layer
* Power BI Dashboard Development

The objective is to provide team, player, venue, and season-level insights through an interactive analytics platform.

---

## Project Progress

* Data quality verification

* Head-to-Head View

3. Batting Analytics Dashboard

5. Venue Analytics Dashboard
6. Head-to-Head Analytics Dashboard

Dashboard Features:

* KPI Cards
