# IPL Performance Analytics System

End-to-end IPL Performance Analytics Intelligence System built using PostgreSQL, SQL, Python, Power BI, and Machine Learning.

## Project Overview

This project analyzes historical IPL match and ball-by-ball data to generate team, player, venue, and season-level insights. The system follows a complete analytics workflow from data ingestion and cleaning to reporting, dashboards, and predictive analytics.

## Technology Stack

* PostgreSQL
* SQL
* Python
* Power BI
* Machine Learning
* Git & GitHub
